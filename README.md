# 🧑‍💻 Aditya Singh — Personal Portfolio

My personal developer portfolio built with **React 19**, **Vite**, **Tailwind CSS v4**, **Framer Motion**, and **GSAP**. Features smooth scroll-based slide navigation, a custom cursor, animated text effects, and sections showcasing my skills, projects, and contact info.

---

## 🚀 Deployment
> 🚀 **Live App:** [portfolioaadiityaasingh.vercel.app](https://portfolioaadiityaasingh.vercel.app/)  

---

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Framework | React 19 + Vite 8 |
| Styling | Tailwind CSS v4 |
| Animations | Framer Motion + GSAP |
| Icons | Lucide React + React Icons |
| HTTP Client | Axios |
| Linting | ESLint v10 |

---

## ✨ Features

- 🖱 **Custom Cursor** — Smooth custom cursor that follows the mouse
- 🎞 **Slide Engine** — Scroll-based full-page slide navigation via `SliderEngine`
- ✍️ **Text Animations** — Typewriter-style text via `TextType` component
- 🦸 **Hero Section** — Intro with name, role, and animated entrance
- 🧠 **Skills Section** — MERN stack and dev tools showcase
- 👤 **About Section** — Background, bio, and personal info
- 🗂 **Projects Section** — Showcase of built projects
- 📬 **Contact Section** — Get in touch form/links

## ⚙️ Getting Started

### Prerequisites

- Node.js v18+
- npm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/aadiityaasingh/portfolio_aadiityaasingh
cd client

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

### Scripts

```bash
npm run dev       # Start development server
npm run build     # Build for production
npm run preview   # Preview production build
npm run lint      # Run ESLint
```
